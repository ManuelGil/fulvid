# Fulvid 0.3.0

A standalone desktop editor for Markdown and MDX.

Released 2026-09-10.

The file on disk is the source of truth. Monaco is the live editor. MDX is not executed. Preview is inert Markdown.

## What's new

- Native Full Screen for the application window (View menu). Host-owned window fullscreen, not web Document Fullscreen, independent of Writing Focus, and not persisted. F11 on Windows and Linux; Ctrl+Cmd+F on macOS. Normal window bounds are not saved while the window is fullscreen.
- Writing Focus on the editor route hides the chrome that gets in the way of writing while Monaco stays the editor. Session-only; not Graph Focus; not Full Screen. Still Ctrl+Shift+F / Cmd+Shift+F. Also available from Quick Actions (Fulvid group, beside Preview).
- Back to top control in the editor for long documents. It appears after you scroll down and returns to the start of the document without changing the text.

## Platform notes

- Linux native fullscreen uses X11/XWayland through Electrobun 2.0.1; native Wayland fullscreen is not provided.
- Windows and macOS native fullscreen use the host `BrowserWindow` APIs. Confirm hit-testing and input on each target machine before treating a build as release-ready for that platform.

## Known limits

- Linux uses an HTML application menu. Electrobun implements the native bar on macOS and Windows only.
- Unsigned builds may need an OS security approval before they run.
- Preview does not run document HTML or MDX. Images are placeholders (no network).
- Packaged "Open with Fulvid" is not delivered. Electrobun 2.0.1's launcher does not forward file arguments to the app. There are no Windows or macOS file associations for the same reason. Native Open File and Open Folder still work.
