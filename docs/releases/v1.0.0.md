# Fulvid 1.0.0

First stable release. Graph keyboard scope, Settings keyboard navigation, Sponsors from About, and tighter folder-scan / document-name boundaries on top of the 0.12.0 editor surface.

## Highlights

- **First stable (1.0.0)**: same product identity and distribution channel as earlier builds; versioning moves out of 0.x.
- **Graph keyboard scope**: application shortcuts apply in the main Graph stage after Context closes, without treating shell chrome as in-scope.
- **Settings navigation**: category arrow-key movement and clearer Editor / Interface wording.
- **Sponsors**: Settings -> About opens GitHub Sponsors in the system browser.
- **Folder boundaries**: scan stays inside the open Folder (no symlink/junction follow-out); create/save refuse trailing spaces and reserved device stems more consistently.

## Notes

- Untitled draft recovery and Session Change Markers from 0.12.0 remain ephemeral (not filesystem autosave; not Git history).
- MDX remains inert source. Export HTML behavior is unchanged.
- Extension packs stay local Lua under `userData/extensions/`; Fulvid ships no packs in-tree.
