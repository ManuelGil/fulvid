# Fulvid 0.2.0

A standalone desktop editor for Markdown and MDX.

Released 2026-09-10.

The file on disk is the source of truth. Monaco is the live editor. MDX is not executed. Preview is inert Markdown.

## What's new

- Opening a folder that has no Markdown or MDX, after a complete scan, is refused and said out loud. A partial scan is not treated as an empty folder.
- Documents keep their own line endings (LF or CRLF). Untitled notes use the New document line endings setting. The statusbar shows the active ending; click to switch. Save writes it.
- When no folder is open, recent folders sit with the empty state.
- The statusbar groups document, mode, format, stats, and folder context, and hides document-only items when nothing is open.
- The existing chrome is fully reachable from the keyboard, with visible focus and accessible names on icon-only controls.

## Known limits

- Linux uses an HTML application menu. Electrobun implements the native bar on macOS and Windows only.
- Unsigned builds may need an OS security approval before they run.
- Preview does not run document HTML or MDX. Images are placeholders (no network).
- Packaged "Open with Fulvid" is not delivered. Electrobun 2.0.1's launcher does not forward file arguments to the app. There are no Windows or macOS file associations for the same reason. Native Open File and Open Folder still work.
