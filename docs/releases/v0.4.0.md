# Fulvid 0.4.0

A standalone desktop editor for Markdown and MDX.

Released 2026-09-11.

The file on disk is the source of truth. Monaco is the live editor. MDX is not executed. Preview is inert Markdown.

## What's new

- Quick Open (`Ctrl/Cmd+P`): find a document in the open Folder by title, filename, or relative path and open it. Keyboard-first (filter, Up/Down, Enter, Escape). Not content search and not a Command Palette. Opens through the existing folder document path (`openOrActivate` -> `selectDocument`); it does not add grants or bypass containment.
- Global Search moves to `Ctrl/Cmd+Shift+F`. Writing Focus moves to `Ctrl/Cmd+Shift+Enter` so those chords do not compete. Monaco local find stays `Ctrl/Cmd+F`.

## Platform notes

- Shortcuts use the same `Ctrl/Cmd` convention as the rest of Fulvid (`ctrlKey` or `metaKey` in the renderer; native menu accelerator `p` for Quick Open where the host owns the application menu).
- Quick Open matches against folder-relative paths from the scan (`/` separators). Typing `\` is normalized to `/` for matching.
- Linux native fullscreen uses X11/XWayland through Electrobun 2.0.1; native Wayland fullscreen is not provided.
- Windows and macOS native fullscreen use the host `BrowserWindow` APIs.

## Known limits

- Linux uses an HTML application menu. Electrobun implements the native bar on macOS and Windows only.
- Unsigned builds may need an OS security approval before they run.
- Preview does not run document HTML or MDX. Images are placeholders (no network).
- Packaged "Open with Fulvid" is not delivered. Electrobun 2.0.1's launcher does not forward file arguments to the app. There are no Windows or macOS file associations for the same reason. Native Open File and Open Folder still work.
- Breadcrumbs are not part of this release. Explorer, Search, Quick Open, and path/context cover document identification.
