# Fulvid 0.5.0

Strong Writing Focus and configurable document location.

## Highlights

- **Document location** (Settings -> Editor): Main panel, Window title, or Hidden - one projection from the open buffer, never a filesystem grant.
- **Strong Writing Focus** (`Ctrl/Cmd+Shift+Enter`): collapses the left sidebar to the compact rail (restores on exit), hides tabs/statusbar/format bar, expands the editor, keeps identity per Document location. Still independent of native Full Screen (F11 / Ctrl+Cmd+F on macOS).
- Clearer orientation for nested paths and duplicate basenames on tabs, with less redundant chrome.

## Notes

- Breadcrumbs and path-segment navigation are not part of this release.
- The right sidebar is not auto-closed in Writing Focus.
- Window title uses a single host capability (`setWindowTitle`); it does not widen filesystem RPC.
