# Fulvid 0.1.0

A standalone desktop editor for Markdown and MDX.

Released 2026-09-09.

The file on disk is the source of truth. Monaco is the live editor. MDX is not executed. Preview is inert Markdown.

## What this version includes

- Edit `.md`, `.markdown`, and `.mdx` locally, with or without an open folder.
- Native Open File, Save As, and Open Folder dialogs.
- One link mode at a time (Markdown or Wikilink).
- Preview and Export HTML from the same inert renderer.
- Explorer, Global Search, Outline, Graph, and Document Context when a folder is open.
- English and Spanish chrome. Document text is not translated.

## Known limits

- Linux uses an HTML application menu. Electrobun implements the native bar on macOS and Windows only.
- Unsigned builds may need an OS security approval before they run.
- Preview does not run document HTML or MDX. Images are placeholders (no network).
