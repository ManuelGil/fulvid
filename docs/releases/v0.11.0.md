# Fulvid 0.11.0

Application chrome localization for five additional languages, with English and Spanish wording refined to match current UI context.

## Highlights

- **German, French, Italian, Dutch, and Portuguese** application chrome alongside English and Spanish. Settings -> Language lists native endonyms. Document text, filenames, and extension-pack copy stay untranslated.
- Refined English and Spanish wording for Search idle state, Graph and Focus labels, folder status, keyboard help, Document Location, and extension size-limit messages.

## Notes

- Language selection changes Fulvid menus, Settings, and messages. Documents stay in the language you wrote them in.
- Extension packs keep their own titles and notify text; the host does not translate pack-owned copy.
- README / document starters and decorative theme-preview mock labels are not part of the host locale catalogs.
- MDX remains inert source. Export HTML behavior is unchanged.
