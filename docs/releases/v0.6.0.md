# Fulvid 0.6.0

Session-local document annotations and clearer Quick Actions ordering.

## Highlights

- **Document annotations**: temporary plain-text notes on a tracked line in the open document. Primary entry is Quick Actions **Add annotation** / **Edit annotation** (Edit group). Same command from Navigate -> Annotate and the glyph margin. Notes are session-local and document-local; they never write to the file and do not mark it dirty.
- **Show/Hide document annotations** stays on View (and Settings -> Editor for the preferred default). It is presentation only, not a Quick Action toggle.
- **Quick Actions**: explicit presentation and overflow metadata so toolbar and More stay deterministic. Annotation sits with Edit; Preview, Writing Focus, and Explorer remain Fulvid surfaces. Global Search uses a distinct icon from local Find.
- **Accessibility**: More mirrors disabled actions; Writing Focus no longer steals keyboard focus to the sidebar rail when collapsing or restoring it.

## Notes

- Annotations are not Search, Graph, Outline, Preview, or persistence features.
- Settings Search is **deferred to 0.7.0**: Settings remains browsable across eight categories (~40 preferences). Search would need extra metadata and per-setting focus infrastructure disproportionate to this release.
- Contributor-only Linux HMR / WebKitGTK XWayland console noise is documented in CONTRIBUTING.md. It is not a 0.6.0 product feature.
