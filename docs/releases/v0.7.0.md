# Fulvid 0.7.0

Document creation, Markdown authoring helpers, Settings Search, and rename reference continuity.

## Highlights

- **New Document from README**: seed a README-shaped Markdown body when creating a document (File -> New, Quick Actions, Explorer). Blank New Document stays available; the editor tab New control still creates a blank document. One built-in body only - not a template manager.
- **Insert document link** / **Insert table of contents**: Edit menu and Quick Actions insert ordinary Markdown or Wikilink text using the active `linkMode` (document, optional heading, or same-document TOC). No live TOC sync.
- **Settings Search**: find preferences on the Settings page by label, description, and category in the current language. Does not search documents or the Folder.
- **Explorer rename**: after a successful rename, resolvable DocumentLink targets that pointed at that document are rewritten (open buffers and closed scanned notes), preserving labels and `#` fragments. Partial update failures are reported; not a multi-file transaction.
- **Appearance**: default theme follows the operating system (`system`); Light/Dark in Settings still force a skin.
- **Global Search**: exact text and regular expression only. Extra strategies are removed.
- **Context**: Graph and Document Context always use the open Folder; Context root is gone.
- **Menus**: clearer Explorer/Search path actions, tab Close others / Close all, and the native WebView/browser context menu is suppressed.

## Notes

- Settings Search, deferred from 0.6.0, ships in this release.
- Rename reference continuity is deterministic DocumentLink rewrite, not a generic refactoring engine.
- MDX remains inert source. Preview and Export HTML behavior are unchanged.
- Contributor-only Linux HMR / WebKitGTK XWayland console noise remains documented in CONTRIBUTING.md; it is not a product feature.
