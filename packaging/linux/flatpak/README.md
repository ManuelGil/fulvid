# Flatpak

Notes only. Not submitted to Flathub. There is no Flatpak manifest.

Do not add a manifest, enable `build.linux.flatpak`, grant `--filesystem=home`, or share the network at build time as a shortcut. Electrobun can emit a post-build Flatpak recipe on Freedesktop Platform; that runtime does not provide WebKitGTK 4.1.

Candidate AppStream id `dev.imgil.fulvid` is recorded in [../metainfo/](../metainfo/). It is not adopted. The shipping Electrobun identifier remains `fulvid.imgil.dev`.
