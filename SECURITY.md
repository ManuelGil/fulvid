# Security

Report vulnerabilities privately. Do not open a public issue for an exploitable host, filesystem, grant, or document-execution bug.

Email: [support@imgil.dev](mailto:support@imgil.dev)

Include the Fulvid version or commit, the platform, and enough detail to reproduce. We will acknowledge the report and work on a fix before any public disclosure.

Filesystem trust boundary, Preview inertness, and grants: [docs/INVARIANTS.md](docs/INVARIANTS.md). How those properties are reviewed: [docs/SECURITY-AND-RESILIENCE.md](docs/SECURITY-AND-RESILIENCE.md). Extension Engine contract and accepted limitations: [docs/EXTENSIONS.md](docs/EXTENSIONS.md). Production promotion gates: [docs/EXTENSION-PRODUCT-CONTRACT.md](docs/EXTENSION-PRODUCT-CONTRACT.md).
