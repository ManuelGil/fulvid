# Experimental Lua spike fixtures

These packs are **not** part of the permanent `extensions/` architectural set.

- Permanent fixtures teach Phase 1 boundaries (`local.capability-notify`, `local.declarative-pack`).
- Fixtures here exercise the wasmoon host spike (notify, editor selection) and may be deleted with the spike.

Copy a pack into `userData/extensions/<id>/` only when experimenting locally. Restart Fulvid after copying (discovery is startup-only).
